# pk-market-analysis

Data analyses of Pakistani markets and macro data, each written up as a short LinkedIn post. Every folder contains the question, the method, the result and the code to reproduce it.

| Date | Analysis | Question |
|---|---|---|
| Nov 2026 | [CPI base effects](2026-11-cpi-base-effects/) | Did inflation really fall in October, and where does the base push it next? |
| Nov 2026 | [KSE-100 fat tails](2026-11-kse100-fat-tails/) | How rare was a 4.5% week, and how wrong is the bell curve about market crashes? |
| Nov 2026 | [KSE-100 volatility clustering](2026-11-kse100-volatility-clustering/) | Does a big move today predict a big move tomorrow, and does it hold outside crises? |
| Nov 2026 | [SBP inflation target path](2026-11-sbp-inflation-target/) | How low can FY27 inflation average, and what would the SBP's 5.5-7.5% July projection require? |

## Setup

```bash
pip install -r requirements.txt
```

Raw data files are not committed (see `.gitignore`). Each folder's README explains where to download the data.
